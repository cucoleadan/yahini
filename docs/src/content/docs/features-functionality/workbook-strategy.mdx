The **Workbook** tab holds the keywords you chose to write about. Each one is a task that moves from idea to published.

<Screenshot name="workbook" alt="Workbook table with task status, assignees, due dates and content state" />

## Three layouts

Switch between them at the top of the tab. Your filters carry over.

- **Table**: every task with its keyword data, status, assignees, due date and content. Sortable, like the Keywords tab.
- **Board**: a column for each status. Drag a card to change its status.
- **Calendar**: tasks on their due dates, a month at a time.

## Task statuses

| Status | Meaning |
| --- | --- |
| **Not started** | Planned, nothing written yet. |
| **Brief ready** | The brief is written. |
| **In progress** | Someone is working on it. |
| **Draft ready** | The draft is written. |
| **In review** | Waiting for a review. |
| **Needs revisions** | The review asked for changes. |
| **Published** | Live on your site. |
| **Archived** | No longer planned. |

Yahini moves a task to **Brief ready** or **Draft ready** when it finishes writing that document. If you drag a card to Brief ready or Draft ready before the document exists, Yahini offers to write it.

## Open a task

<Screenshot name="task" alt="A task panel: status, due date, assignees, keyword details and Search Console" />

Click a task to open its panel. There you can:

- set the **Status**, **Assignees** and **Due date**;
- edit the **working title**, **priority** and **funnel stage**;
- add or remove **secondary keywords**, up to 10;
- write a **description** for whoever works on it;
- **Generate brief** or **Generate draft**, 1 credit each. See [Briefs and drafts](/features-functionality/briefs-and-drafts/);
- open the brief or draft once it exists.

If the project is connected to Search Console, the panel also shows how the keyword's searches perform.

Viewers on the project's team see tasks read-only. See [Teams and roles](/account/team/).

## Filter the workbook

Besides the keyword filters, the workbook can be filtered by:

- **Task status**, including **In progress (any)**, which covers everything started but not yet published;
- **Due date**: **Overdue** shows tasks past their due date that aren't published or archived;
- **Assignee**: assigned to you, unassigned or a team member.

The numbers on the project dashboard link to these filtered views.

## All your tasks

The **Tasks** page in the sidebar shows every workbook task across all your projects, with a project column. It has the same table, board and calendar layouts.

## Remove a keyword from the workbook

Select it in the table and choose **Hide**. It leaves the workbook and moves to the Keywords tab's Hidden view.
