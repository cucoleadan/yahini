## The dashboard

Each project opens on its dashboard.

<Screenshot name="dashboard" alt="Project dashboard with Search Console totals, clicks per day and upcoming tasks" />

- **Search Console**: clicks, impressions, CTR and average position, compared with the previous period, plus clicks per day and your top movers. This appears once you [connect Search Console](/features-functionality/search-console/).
- **Project numbers**: keywords, how many are in the workbook, in progress, published and overdue. Each number links to the matching list.
- **Task status** and **Upcoming tasks**: where the workbook stands and what's due next.
- **Project**: the website, country, language, competitors, topics and audience, and how much of the brand profile is filled in.
- **Team**: who has access, and pending invitations. See [Teams and roles](/account/team/).

## Project settings

Open the **⋯** menu next to the project name:

| Option | What it does |
| --- | --- |
| **Connect Search Console** / **Search Console connection** | Links the project to a Google Search Console property. |
| **Edit topics & audience** | Changes the topics and audience that focus research. |
| **Competitors** | Changes a competitor or gets its keywords. See [Competitors and topics](/features-functionality/competitors-and-topics/). |
| **Expand topics** | Finds keywords for a feature or theme your list is missing. |
| **Rename** | Changes the project name. Leave it empty to show the website address. |
| **Archive** | Moves the project to the archive. |

## Archive and restore

Archiving a project moves it to **Projects › Archived**. Its keywords, briefs, drafts and tasks are kept, and it no longer counts toward your plan's project limit.

Only the project owner or a team admin can archive or restore a project. To restore one, open the **Archived** view in Projects and choose **Restore**. A restored project counts toward your limit again, so you might need to archive another project or upgrade first.

## Project statuses

| Status | Meaning |
| --- | --- |
| **Ready** | Nothing running. |
| A running step, such as **Generating keywords** | An agent is working on the project. |
| **Needs attention** | The last run stopped. Its credits were refunded and retrying is free. |
| **Archived** | In the archive. |
